# Probabilidade para Ciência de Dados

Projeto de estudos aplicado à **Probabilidade e Estatística**, com foco em raciocínio quantitativo para análise de dados.

## Objetivos
- Explorar probabilidade descritiva e condicional
- Trabalhar distribuições e eventos
- Simular cenários com Python
- Interpretar resultados para tomada de decisão baseada em dados

## Stack
Python • NumPy • Pandas • Matplotlib • SciPy
